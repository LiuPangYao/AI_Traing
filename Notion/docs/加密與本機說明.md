# Notion 的資料放哪裡、會不會連網、加密是什麼

## 全部在本機
- 筆記存在桌面的 `Notion` 資料夾（或你在 ⚙ 設定 → 存檔 改的位置）：一天一個資料夾（`2026-10-30`），一張筆記一個檔（`001.note` 或 `001.md`）。
- 貼的截圖與附件在 `attachments`；設定、視窗狀態、舊版本快照、垃圾桶在 `.app`。
- 備份＝把整個資料夾複製走。加密中的 `.note` 只有原本那個 Windows 帳號讀得到（見下），要搬到別台電腦請用 ⚙ 設定 → 存檔 → 「匯出全部」存成純文字。

## 不連網、不收集
- 不用登入、沒有帳號、不同步到任何雲端，程式不收集也不回傳任何東西。
- 唯一的網路動作：程式開啟幾秒後去 GitHub Releases 讀一次版本號，看有沒有新版（只讀，不傳）。
  要關掉：⚙ 設定 → 更新 → 關「啟動時有新版就提醒我」只關提醒；`Notion.bat` 裡 `set NOTE_UPDATE_CHECK=0` 則完全不查。
- 公司電腦擋外網時，更新檢查只會顯示「查不到」，其他功能照常。

## 加密（預設開）
- 用 Windows 內建的 DPAPI（`CryptProtectData`）把每張筆記鎖在**你登入的這個 Windows 帳號**上；沒有密碼可以設、也不用記。
- 同一台電腦、同一個帳號登入就自動解開；別人把檔案拷走、換一個帳號、重灌系統或換電腦，都打不開，而且**沒有任何方法救回來**。
- 所以：換電腦、重灌、換帳號之前，先「匯出全部」成 `.md`；或在 ⚙ 設定 → 存檔 關掉加密（關掉後筆記就是普通的 `.md` 文字檔，誰都能讀）。
- 附件（截圖、檔案）不加密，只有筆記內文加密。
- 加密擋的是「檔案被拿走」。同一個帳號登入時，任何程式都能解開，所以離開座位請鎖定電腦。
- Linux／macOS 沒有 DPAPI，筆記一律是純文字。

## 更新怎麼做
1. 有新版時程式會提醒（或 ⚙ 設定 → 更新 → 重新檢查）。
2. 按「下載新版」用瀏覽器下載 zip。
3. 關掉 Notion，把 zip 裡的 `Notion.exe` 蓋掉原本的，再開。筆記與設定在資料夾裡，不會動到。
