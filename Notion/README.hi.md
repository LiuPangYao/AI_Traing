# Notion

Windows के लिए एक लोकल स्टिकी-नोट्स ऐप। हर दिन का एक फ़ोल्डर, हर नोट की एक फ़ाइल, और सब कुछ आपके अपने PC पर रहता है: कोई क्लाउड नहीं, कोई खाता नहीं, कुछ भी इकट्ठा नहीं किया जाता।
Python 3.12 में लिखा गया है (UI: tkinter + customtkinter; पैकेजिंग: PyInstaller)।

> यह फ़ोल्डर केवल टूल का कोड और संरचना साझा करता है। इसमें उपयोगकर्ता के नोट्स या कोई अन्य डेटा नहीं है।

साइड पैनल नोट्स को दिन के हिसाब से दिखाता है; शीर्षक से पहले ☆ पसंदीदा का निशान है। बीच में शीर्षक और टेक्स्ट है: `==हाइलाइट==`, `!!लाल!!`, `**बोल्ड**` टाइप करते ही रंगीन हो जाते हैं, ``` ब्लॉक पर Copy बटन मिलता है, और स्क्रीनशॉट सीधे नोट में दिखते हैं। भाषा, शॉर्टकट, साइड पैनल की जगह और अपडेट सब ऊपर दाईं ओर ⚙ सेटिंग्स में हैं।

## उपयोग कैसे करें

**बस उपयोग करें**: पैकेज किया हुआ zip (`Notion.exe` + `Notion.bat` + दो .txt गाइड, `tools/make_release.py` से बना) कहीं भी अनज़िप करें।

**क्लोन करके बदलें** (इस फ़ोल्डर में exe नहीं है):
```
pip install -r requirements.txt
python -m personalnote          # चलाएँ
build_exe.bat                   # या dist\Notion.exe बनाएँ (पहले टेस्ट चलते हैं)
```
इस फ़ोल्डर में `Notion.bat` पर डबल-क्लिक भी काम करता है: exe न मिलने पर यह Python और पैकेज जाँचता है और बताता है कि क्या कम है।

1. Windows 10 / 11 (64-बिट) चाहिए। पैकेज किए संस्करण के लिए कुछ इंस्टॉल नहीं करना पड़ता।
2. `Notion.bat` चलाएँ (.bat में नोट्स फ़ोल्डर, भाषा, फ़ॉन्ट, अपडेट जाँचना है या नहीं आदि सेट कर सकते हैं; खाली = ऐप की सेटिंग्स)। पहली बार Windows "Windows protected your PC" → "More info" → "Run anyway" दिखा सकता है (exe हस्ताक्षरित नहीं है)।
3. नोट्स डिफ़ॉल्ट रूप से डेस्कटॉप के `Notion` फ़ोल्डर में रहते हैं; ⚙ सेटिंग्स → फ़ाइलें में बदलें।
4. Windows के साथ शुरू करने के लिए: Win+R, `shell:startup` टाइप करें और वहाँ `Notion.bat` का शॉर्टकट रखें (सेटिंग्स → फ़ाइलें में "स्टार्टअप फ़ोल्डर खोलें" बटन है)।

शॉर्टकट (डिफ़ॉल्ट; सेटिंग्स में बदलें): Ctrl+N नया नोट (आज), Ctrl+T आज, Ctrl+F खोज, Ctrl+S अभी सहेजें, Ctrl+\ साइड पैनल, Ctrl+PgUp / PgDn पिछला / अगला दिन, Ctrl+H / Ctrl+Shift+H हाइलाइट / लाल, Ctrl+B / I बोल्ड / इटैलिक, Ctrl+Shift+C कमांड ब्लॉक, Ctrl+= / Ctrl+- फ़ॉन्ट आकार।

## डेटा कहाँ रहता है

```
Notion/                       ← नोट्स फ़ोल्डर (पूरे फ़ोल्डर का बैकअप लें)
  2026-10-28/001.note         ← हर नोट की एक फ़ाइल; .note एन्क्रिप्टेड, .md सादा; पहली पंक्ति "# शीर्षक"
  attachments/                ← चिपकाए चित्र और अटैचमेंट (एन्क्रिप्टेड नहीं)
  .app/settings.json          ← ऐप सेटिंग्स (शॉर्टकट, अपडेट रिमाइंडर सहित); state.json विंडो स्थिति और पैनल की जगह;
                                 order.json मैनुअल क्रम; favorites.json पसंदीदा; history/ स्नैपशॉट; trash/; error.log
%LOCALAPPDATA%\PersonalNote\logs   ← personalnote.log, crash.log; rescue/ रेस्क्यू फ़ाइलें
```

एन्क्रिप्शन क्या ढकता है: नोट का टेक्स्ट और स्नैपशॉट। अटैचमेंट, निर्यात की गई .md फ़ाइलें और ट्रैश के फ़ाइल नाम एन्क्रिप्टेड नहीं होते। एन्क्रिप्शन Windows खाते से बँधा है: नया PC, रीइंस्टॉल या हटाया गया खाता नोट्स नहीं खोल सकता, इसलिए पहले सब निर्यात करें।

ऐप शुरू होने पर GitHub से एक बार संस्करण संख्या पढ़ने के अलावा कहीं कनेक्ट नहीं होता; `Notion.bat` में `set NOTE_UPDATE_CHECK=0` उसे भी बंद कर देता है।

## समर्थित सिस्टम और लाइसेंस

- Windows 10 / 11 मुख्य प्लेटफ़ॉर्म है; Windows 7 / 8.0 पर नहीं चलता (Python 3.12 को 8.1+ चाहिए), `Notion.bat` समझाकर रुक जाता है।
- Linux: OS-विशिष्ट सब कुछ `platform_.py` में है; `Notion.sh` / `build_linux.sh` चलाते और पैकेज करते हैं; एन्क्रिप्शन और ड्रैग-ड्रॉप नहीं; असली हार्डवेयर पर अभी परीक्षण नहीं हुआ।
- फ़ॉन्ट फ़ाइलें शामिल नहीं हैं, सिस्टम फ़ॉन्ट उपयोग होते हैं। तृतीय-पक्ष घटक: Python (PSF), Tcl/Tk (BSD-शैली), customtkinter (MIT), Pillow (MIT-CMU), PyInstaller (अपवाद सहित GPL)।

## ज्ञात सीमाएँ

- एन्क्रिप्शन Windows खाते से बँधा है (ऊपर देखें)। "फ़ोल्डर बदलें" पुराने नोट्स नहीं ले जाता।
- चित्र केवल कोने के हैंडल से अनुपात में बदलते हैं; GIF चलते नहीं।
- Windows अचानक बंद हो तो आख़िरी 1.2 सेकंड का टाइपिंग खो सकता है।
- एक ही फ़ोल्डर पर दो इंस्टेंस (जैसे RDP और लोकल) से सुरक्षा नहीं है; बाद वाला सेव जीतता है।
- साइड पैनल एक बार में अधिकतम 1000 नोट दिखाता है; बाकी के लिए खोज का उपयोग करें।
- exe हस्ताक्षरित नहीं है, इसलिए SmartScreen पहली बार एक बार रोकता है।
