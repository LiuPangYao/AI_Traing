# Notion

Windows 向けのローカル付箋メモアプリ。1 日 1 フォルダー、1 メモ 1 ファイルで、すべて自分の PC に保存されます。クラウドもアカウントも使わず、何も収集しません。
Python 3.12 製（画面：tkinter ＋ customtkinter、パッケージ：PyInstaller）。

> このフォルダーはツールのコードと構成だけを共有しています。利用者のメモやその他のデータは含みません。

サイドパネルには日付ごとにメモが並び、タイトル前の ☆ はお気に入り。中央はタイトルと本文で、`==強調==`、`!!赤字!!`、`**太字**` は入力しながら色づき、``` ブロックには「コピー」ボタン、スクリーンショットはそのまま表示されます。言語、ショートカット、サイドパネルの位置、更新は右上の ⚙ 設定にあります。

## 機能

| 機能 | 内容 |
|---|---|
| 日付ごとのメモ | サイドパネルは 1 日 1 グループ、1 日に何枚でも。日付をクリックで折りたたみ。メモを長押ししてドラッグで同じ日の中の並べ替え。「別の日に追加」は日付を選んでから追加（過去の記録用）。「＋ 新しいノート」／Ctrl+N は常に今日に追加 |
| お気に入り | タイトル前の ☆ をクリックで ★ に。いちばん上（To-do の下）に「★ お気に入り」グループが現れ、クリックでそのメモを開く。もう一度クリックで解除 |
| To-do | いちばん上に赤字で固定表示される 1 枚。どの日付にも属さない（`9999-12-31` フォルダーに保存されるため常に先頭） |
| チェックリスト | 行頭の `- [ ] `（書式バーの「チェック」または手入力）が四角になり、クリックでチェック、完了は取り消し線。ファイルには GitHub 形式の `- [x]` |
| #タグ | 本文の `#projectA` はアクセント色で表示。Ctrl+クリックでそのタグをサイドパネルで検索 |
| 右クリックメニュー | 本文とタイトル：切り取り、コピー、貼り付け（クリップボードがスクリーンショットなら画像に）、すべて選択、プレーンテキストとしてコピー。メモ行：開く、今日にコピー、エクスポート、以前のバージョン、お気に入り、共有、削除。日付見出し：この日に追加、その日を 1 つの `.md` にエクスポート、その日を消去 |
| 自動保存 | 入力を止めて 1.2 秒で保存。切り替え時・終了時も保存。保存できないときは救済ファイルを残す |
| 記号 | 文字を選んで `==強調==`（黄色）、`!!警告!!`（赤）、`**太字**`、`*斜体*`。ファイルには記号がそのまま入るので、エクスポートしても読める。記号はカーソル行以外では隠れる |
| コマンドブロック | ``` ブロックは等幅・暗い背景で、先頭の「コマンド｜コピー」でブロック全体をコピー（よく使うコマンドやプロンプトに） |
| リンク | URL と Windows のパス（`\\server\...` を含む）は自動でリンクに。Ctrl+クリックで開く。実行ファイルは確認してから |
| 画像とファイル | Ctrl+V でスクリーンショットをそのまま貼り付け、角のハンドルでサイズ変更。`.md`／`.txt`（1 MB 以内）をウィンドウにドロップすると今日のメモに。他のファイルは受け付けない（添付は 📎） |
| リスト | 行頭の `1. `／`- ` は Enter で次の項目が続く |
| 検索 | Ctrl+F、日付または本文。件数が多いと「検索中」を表示 |
| ショートカット | 設定 → ショートカット：各機能のキーを自由に変更。Ctrl か Alt を含めること、システムのコピー／貼り付けキーは使えない、2 つの機能に同じキーは不可。すべて既定に戻せる |
| 暗号化 | 既定でオン。Windows アカウント（DPAPI）に結び付けるので、ドライブを別の PC に移しても読めない。PC を替える前に「すべてエクスポート」。詳細は [docs/加密與本機說明.md](docs/加密與本機說明.md)（zip に .txt 版あり） |
| インポート／エクスポート | 1 枚、1 日分（1 ファイルに）、または全部をプレーンな `.md` に。`.md`／`.txt` のインポート（UTF-8、UTF-16、Big5、GBK、Shift-JIS を自動判別） |
| バージョンとごみ箱 | 各メモは以前のスナップショットを保持（右クリック「以前のバージョン…」で表示・復元。復元前に現在の内容も残す）。削除はまずごみ箱へ。「前回の削除を元に戻す」で復帰 |
| 共有 | メモ行を右クリック → 共有：メールで送る（メールアプリを開く。件名＝タイトル、本文＝プレーンテキスト）、Google Drive デスクトップ版の同期フォルダーにコピー（見つからなければフォルダーを選択） |
| 多言語 | 英語（既定）、繁体字中国語、簡体字中国語、日本語。設定 → 外観で切り替え、再起動不要。翻訳表は 1 つの csv で、列を足せば言語を追加できる |
| 更新 | 起動後数秒で GitHub Releases に新しいバージョンがあるか確認（バージョン番号を読むだけ）。あれば通知：zip をダウンロード、このバージョンはスキップ、または通知をオフ（設定 → 更新）。更新＝アプリを閉じて `Notion.exe` を置き換えるだけ。メモと設定はそのまま |
| カレンダーと使用時間 | ツールバー「カレンダー」または Ctrl+M：今月どの日にメモがあり、毎日どれだけ使ったか（ヒートマップ）。日付をクリックで移動。時間はウィンドウにフォーカスがあり操作中のときだけ加算され、`.app/usage.json` に保存。設定 → ヘルプ → バージョン履歴に各バージョンの変更点 |
| ノートリンクとテンプレート | 本文に `[[タイトル]]`（またはノートを右クリック →「ノートリンクをコピー」）と書き、Ctrl+クリックで移動。「戻る」（Alt+Left）で前のノートへ。「新しいノート ▾」でテンプレートから作成（.app/templates に追加可）。ツールバー「未完了」（Ctrl+L）は未チェック項目を一覧表示しテキストとしてコピー可。設定 → 保存 で期間エクスポート。リスト行で Tab インデント。検索欄の下に最近の #タグ |
| 使い方ガイド | 初回起動時に 5 ページのガイド。1 回だけ表示。設定 → ヘルプからもう一度見られる |
| 外観 | ライト／システム／ダーク。Ctrl+ホイールでズーム。サイドパネルは左／右／下、幅はドラッグで変更。書式バーは折りたたみ可。空のメモにはヒント。「保存しました」はフェードアウト。ダイアログはメインウィンドウの中央に開く |
| その他 | 単一インスタンス。スプラッシュ画面。時間のかかる処理は進捗表示。行数と文字数。深夜 0 時を過ぎると「今日」の印が自動で移る |

## 使い方

**使うだけ**：パッケージ済みの zip（`Notion.exe` ＋ `Notion.bat` ＋ 2 つの .txt ガイド。`tools/make_release.py` が生成）を好きな場所に展開します。

**clone して改造する**（このフォルダーに exe はありません）：
```
pip install -r requirements.txt
python -m personalnote          # 実行
build_exe.bat                   # または dist\Notion.exe をビルド（先にテストが走る）
```
このフォルダーの `Notion.bat` をダブルクリックしても動きます。exe が見つからないときは Python とパッケージを確認し、足りないものを教えてくれます。

1. Windows 10／11（64 ビット）が必要。パッケージ版は何もインストールしなくて済みます。
2. `Notion.bat` を実行（.bat で保存先、言語、フォント、更新確認の有無などを設定可。空欄＝アプリ内設定を使用）。初回は「Windows によって PC が保護されました」→「詳細情報」→「実行」が出ることがあります（exe は未署名）。
3. メモは既定でデスクトップの `Notion` フォルダーに保存。⚙ 設定 → 保存 で変更できます。
4. Windows 起動時に開く：Win+R で `shell:startup` を開き、`Notion.bat` のショートカットを入れる（設定 → 保存 に「スタートアップフォルダーを開く」ボタンあり）。

ショートカット（既定。設定で変更可）：Ctrl+N 新しいノート（今日）、Ctrl+T 今日、Ctrl+F 検索、Ctrl+S 今すぐ保存、Ctrl+\ サイドパネル切替、Ctrl+PgUp／PgDn 前日／翌日、Ctrl+H／Ctrl+Shift+H 強調／赤字、Ctrl+B／I 太字／斜体、Ctrl+Shift+C コマンドブロック、Ctrl+=／Ctrl+- 文字サイズ。

## データの場所

```
Notion/                       ← メモのフォルダー（丸ごとバックアップすればよい）
  2026-10-28/001.note         ← 1 メモ 1 ファイル。.note は暗号化、.md はプレーン。1 行目は「# タイトル」
  attachments/                ← 貼り付けた画像と添付（暗号化なし）
  .app/settings.json          ← アプリ内設定（ショートカット、更新通知を含む）。state.json ウィンドウ状態とパネル位置。
                                 order.json 手動の並び順。favorites.json お気に入り。history/ スナップショット。trash/ ごみ箱。error.log
%LOCALAPPDATA%\PersonalNote\logs   ← personalnote.log、crash.log（ハング時のスタック）。rescue/ 救済ファイル
```

暗号化の範囲：メモ本文とスナップショット。添付、エクスポートした .md、ごみ箱内のファイル名は暗号化されません。暗号化は Windows アカウントに結び付くため、別の PC、再インストール、アカウント削除後は開けません。先に全部エクスポートしてください。

アプリは起動時に GitHub のバージョン番号を 1 回読む以外、ネットワークに接続しません。`Notion.bat` の `set NOTE_UPDATE_CHECK=0` でそれもオフにできます。

## 構成（保守する人向け）

モジュール構成と開発ルールは [README.en.md](README.en.md) の「Architecture」を参照してください（内容は同じです）。

## 開発とパッケージ

```
pip install -r requirements.txt
python -m personalnote                 # 実行
python -m unittest discover -s tests   # 単体テスト
python tools/stress/ui_checks.py       # 実際のウィンドウで一通り確認（画面外に配置）
build_exe.bat                          # dist\Notion.exe をビルド（テストと翻訳表チェックが先に走る）
python tools/make_release.py --dest <フォルダー> [--publish]   # 配布フォルダーと zip。--publish で GitHub Releases にアップロード（gh が必要）
python tools/check_public_words.py     # コミット前に出てはいけない語を検索
```

## 対応 OS とライセンス

- Windows 10／11 が主な対象。Windows 7／8.0 では動きません（Python 3.12 は 8.1 以上）。`Notion.bat` が説明して止まります。
- Linux：OS 依存部分は `platform_.py` に集約。`Notion.sh`／`build_linux.sh` で実行・パッケージ可。暗号化とドラッグ＆ドロップはなし。実機未検証。
- フォントファイルは同梱せず、システムフォントを指定。サードパーティ：Python（PSF）、Tcl/Tk（BSD 系）、customtkinter（MIT）、Pillow（MIT-CMU）、PyInstaller（例外条項付き GPL）。

## 既知の制限

- 暗号化は Windows アカウントに結び付く（上記）。「保存先の変更」は古いメモを移動しない。
- 画像は角のハンドルで等比サイズ変更のみ。GIF は動かない。
- Windows を強制シャットダウンすると最後の 1.2 秒の入力が失われることがある。
- 同じフォルダーで 2 つ同時に起動（RDP とローカルなど）した場合の保護はなく、後から保存した方が勝つ。
- サイドパネルは一度に最大 1000 枚。残りは検索で。
- exe は未署名のため、初回は SmartScreen に一度止められる。
